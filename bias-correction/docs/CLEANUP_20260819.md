# Cleanup record — 19 August 2026

## Outcome

The working directory was reduced from approximately 1.6 GB to 1.0 GB without
removing source code, tests, finalized active caches, canonical completed runs,
or curated model bundles.

Before cleanup, the entire directory was untracked inside the parent
`s2s_anlysis` repository. The cleanup therefore used a conservative rule:
delete only validated, regenerable, or exact-duplicate artifacts; archive the
one scientifically relevant failure trace first.
