# Regional Bias Correction

Clean workspace for developing shared bias-correction code and applying it to
regional forecasting problems.

## Structure

- [`pcb/`](pcb/) — new shared PCB code will be developed here.
- [`india/`](india/) — India regional implementation using `pcb`.
- [`kentucky/`](kentucky/) — Kentucky regional implementation using `pcb`.
- [`previous-work/`](previous-work/) — archived earlier experiments and code.

New development should stay in `pcb`, `india`, or `kentucky`. The archived
projects are retained only as references.
